Workspace-only supporting files that are useful during production work but are not part of the published site.

## Folders
- `ops/`: batch-memory files and operational notes such as `Plan.md`, `Prompt.md`, `Status.md`, and `FailureLog.md`
- `notes/`: backlog, one-off notes, and design memos that do not need to live at the repo root
- `media/`: draft or duplicate media kept for reference while authored assets live under `content/readings/<slug>/`
- `scratch/`: disposable local artifacts that should stay out of the main project surface area
