# Source Audio

Place local lecture-recording audio files in this folder.

- `source_audio/` is source/input material, not a deploy target.
- Keep class recordings under `source_audio/class-recordings/`.
- Canonical filename format is `YYYY-MM-DD-<reading-slug>-class-recording.<ext>`.
- `/UserInput` is only a temporary intake location before files are renamed and moved here.
