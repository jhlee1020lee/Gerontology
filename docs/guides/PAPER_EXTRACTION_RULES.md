# Paper Extraction Rules

논문 원문 추출은 요약이 아니라 보존 작업이다. `full.md`와 `source_segments.json`은 이후 번역, 퀴즈, 교수님 구술 대비의 근거가 된다.

## 논문 유형 구분

- 실증 논문: 연구 질문, 표본, 측정, 분석, 결과, 한계가 추출 핵심이다.
- 리뷰 논문: 검색/선정 방식, 포함 문헌 범위, 종합 논리, 남은 쟁점이 추출 핵심이다.
- 이론 논문: 핵심 개념, 주장 구조, 반론 처리, 적용 범위가 추출 핵심이다.
- 교재 장: 장 구조, 정의, 대비쌍, 예시, 표/그림의 설명 기능이 추출 핵심이다.

## 필수 추출 범위

- 초록
- 도입과 연구 질문
- 이론 또는 선행연구
- 방법, 표본, 측정, 분석
- 결과와 표/그림
- 논의와 제한점
- 부록, 주석, 참고문헌, 출판 이력

## 누락 방지 원칙

- 섹션 순서를 바꾸지 않는다.
- 표와 그림을 “표에서 결과가 제시된다” 같은 문장으로 대체하지 않는다.
- 숫자, 표본 수, 조건, 괄호 안 제한, 인용, 부정 표현을 생략하지 않는다.
- PDF OCR이 흔들리는 곳은 작은 micro-chunk로 분리한다.

## 연구보고 기준 적용

- APA JARS: 연구 질문, 참여자/표본, 방법, 분석, 결과, 한계 항목을 빠뜨리지 않는 체크포인트로 쓴다.
- EQUATOR: 연구 유형별 투명성 체크리스트 방식을 차용한다.
- PRISMA: 리뷰 논문이면 검색 전략, 포함/제외 기준, 문헌 수, 종합 방식을 별도 확인한다.
- IMRaD: 실증 논문의 Introduction, Methods, Results, Discussion 흐름을 segment 순서의 기본값으로 쓴다.

## 실패 조건

- `full.md`가 원문 대신 요약문이면 실패다.
- 본문 일부가 “추후 보완” 상태인데 approved로 표시하면 실패다.
- 표, 그림, 참고문헌, 부록을 이유 없이 누락하면 실패다.
