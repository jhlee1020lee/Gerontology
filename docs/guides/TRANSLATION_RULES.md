# Translation Rules

`한국어 번역`은 원문 전체 번역이지 요약이 아니다. 이 문서는 영어 읽기를 한국어로 옮길 때의 기준이다.

## 원칙

- 원문 논리 순서와 문단 흐름을 유지한다.
- 원문 segment 하나에 번역 segment 하나를 대응시킨다.
- 학술 용어는 첫 등장 시 한국어 뒤에 영어를 병기한다.
- 자연스러운 한국어를 쓰되, 수치/조건/인용/괄호 정보를 줄이지 않는다.
- 과도한 의역, 수업 해석 추가, 결과 과장은 금지한다.

## 절대 금지

- 원문 문단을 “요약하면”, “전반적으로”, “핵심은” 같은 문장으로 대체하기
- 표/그림/수치/인용을 번역 과정에서 누락하기
- 비인과 관계를 인과처럼 번역하기
- 제한점, 가능성, 조심스러운 표현을 확정 표현으로 바꾸기
- 번역문에 논문 밖 수업 해석을 끼워 넣기

## 용어표 기본값

- gerontology: 노년학
- geriatrics: 노인의학
- life-span development: 전생애발달
- cohort effect: 코호트 효과
- period effect: 시대 효과
- age effect: 연령 효과
- cross-sectional: 횡단적
- longitudinal: 종단적
- mortality risk: 사망위험
- social participation: 사회참여
- perceived control: 지각된 통제감
- caregiving: 돌봄
- limitation: 제한점 또는 한계

## 검수 기준

- 원문 segment_id와 번역 segment_id가 일치해야 한다.
- 번역 segment가 원문보다 지나치게 짧으면 축약 의심으로 재검토한다.
- 숫자, 인용, 표/그림 언급은 자동 검사와 수동 spot-check를 모두 통과해야 한다.
