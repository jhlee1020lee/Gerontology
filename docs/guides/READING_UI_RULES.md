# Reading UI Rules

읽기 화면의 목표는 장식이 아니라 가독성, 집중도, 복습 효율이다.

## 본문 레이아웃

- 본문 measure는 대략 60~70ch를 목표로 한다.
- line-height는 긴 글에서 1.8 이상을 유지한다.
- 문단 간격은 줄간격과 분리해 충분히 둔다.
- 제목 계층은 h2, h3, h4를 명확히 구분한다.
- 표와 그림은 본문 흐름 안에서 크게 열어 볼 수 있어야 한다.

## 원문 / 번역 연결

- `translation.html`에서만 원문 보기 토글을 제공한다.
- 원문 보기는 segment 또는 검증된 context block 단위로 작동한다.
- 버튼 문구는 정렬 정밀도를 드러낸다.
- hover-only 공개 방식은 쓰지 않는다.

## 탐색

- 우측 목차는 현재 섹션 active 상태를 표시한다.
- 모바일에서는 목차를 sticky sidebar로 유지하지 않고 본문 위/아래 흐름으로 보낸다.
- 읽기 진행률은 긴 `full.html`, `translation.html`에서만 제공한다.

## 색과 밀도

- 긴 본문은 베이지, 아이보리, 차분한 회색 계열을 기본으로 한다.
- 카드/그림자/강한 색을 남발하지 않는다.
- 태그는 장식이 아니라 복습 키워드로 보이게 한다.

## 접근성

- 텍스트 spacing 변경에도 본문이 겹치지 않아야 한다.
- 토글은 키보드 focus가 보여야 한다.
- 모바일에서 한 줄이 너무 길거나 너무 짧아지지 않아야 한다.
