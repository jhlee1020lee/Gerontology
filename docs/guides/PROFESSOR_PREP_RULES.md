# Professor Prep Rules

`교수님 구술 대비`는 “이 글을 어떻게 읽었는지”를 20~40초로 말하는 답변을 만든다.

## 기본 답변 구조

- 내가 이 글을 무엇 중심으로 읽었는지
- 그 포인트가 왜 새롭거나 중요한지
- 읽기 속 구체 근거가 무엇인지
- 어떤 과장이나 오해를 피해야 하는지

## 필수 필드

- `title`
- `answer_30s`
- 신규/재승인 카드에는 `evidence_segment_id` 또는 명확한 읽기 근거 메모를 둔다.

## 좋은 카드

- 개념 정의보다 읽기 각도나 바뀐 기대를 먼저 말한다.
- 최소 하나의 구체 anchor가 있다: 용어, 변수, 방법, 표본, 결과, 제한점, 한국 맥락.
- follow-up 질문에 버틸 수 있게 대비쌍이나 한계를 포함한다.

## 실패 카드

- `concepts.md`에 그대로 붙여도 어색하지 않은 정의 카드
- “흥미롭다”, “중요하다”만 있고 무엇이 왜 그런지 없는 카드
- 논문 밖 해석을 읽기 근거처럼 말하는 카드
- 40초를 넘는 장문 요약체
