# Readability Checklist

새 논문 페이지를 추가하거나 `full.html`, `translation.html`을 재빌드한 뒤 확인한다.

## Desktop

- [ ] 본문 한 줄이 과도하게 길지 않다.
- [ ] 문단이 5~7줄 이상 계속되면 나눌 수 있는지 검토했다.
- [ ] h2/h3/h4 계층이 명확하다.
- [ ] 표와 그림을 크게 열 수 있다.
- [ ] 우측 목차의 active 상태가 움직인다.
- [ ] 읽기 진행률이 긴 본문에서 작동한다.

## Mobile

- [ ] 목차가 본문을 가리지 않는다.
- [ ] 버튼과 원문 보기 토글이 터치하기 충분하다.
- [ ] 표/그림이 화면 폭을 깨지 않는다.
- [ ] 제목과 카드 텍스트가 겹치지 않는다.

## Translation Reveal

- [ ] 원문 보기 버튼이 `translation.html`에만 있다.
- [ ] 열리는 원문이 해당 한국어 문단의 local topic span과 맞는다.
- [ ] abstract, methods, results/discussion, appendix/backmatter를 spot-check했다.

## Quiz / Review

- [ ] 퀴즈 문항은 evidence_segment_id 또는 legacy source 근거를 표시한다.
- [ ] 오답은 그럴듯하지만 명확히 틀리다.
- [ ] 태그는 복습 키워드로 읽힌다.
