이 글을 어떻게 읽었는지

8개 모델 답변

질문에 먼저 직답한 뒤, 10초·30초·60초 답변과 꼬리질문 대응을 비교하세요. 추상적인 감상보다 개념, 근거, 한계, 한국 맥락을 붙이는 연습에 맞춰져 있습니다.

모델 답변 01

이 글이 우정의 가치를 어떻게 설명하나

30초 모델 답변

우정은 노년기 행복과 건강을 지지하는 핵심 사회적 자원이라고 설명합니다. 친구는 동반성, 정서적 위로, 실질적 도움을 동시에 제공할 수 있습니다.

모델 답변 02

친구관계의 독특한 점을 한 문장으로 말하면

30초 모델 답변

친구는 주어진 관계가 아니라 선택하고 유지하는 자발적 관계라는 점이 핵심입니다. 그래서 비슷한 가치와 관심을 가진 사람들 사이에서 깊어지기 쉽습니다.

모델 답변 03

친구가 건강에 좋다고 할 때 구체적으로 무엇을 뜻하나

30초 모델 답변

친구는 정서적 지지와 실질적 도움, 건강 관련 정보 제공을 통해 건강을 돕는다는 뜻입니다. 외로움과 우울을 줄이고, 병원 정보나 생활습관 조언을 줄 수도 있습니다.

모델 답변 04

친구도 해로울 수 있다는 말은 무슨 뜻인가

30초 모델 답변

친구관계도 신뢰가 깨지거나 비호혜적이면 스트레스와 상처의 원천이 될 수 있다는 뜻입니다. 원치 않는 조언, 자기중심성, 배신은 건강과 안녕을 해칠 수 있습니다.

모델 답변 05

실천적 함의는 무엇인가

30초 모델 답변

전문가와 돌봄체계가 친구를 비공식 지원자원으로 더 적극적으로 활용할 수 있다는 것입니다. 방문, 전화, 이동 지원, 기술 사용 지원 같은 역할에 친구를 포함할 수 있습니다.

모델 답변 06

우정 개입 사례를 왜 중요하게 보나

30초 모델 답변

친구형성과 유지 기술을 가르치는 개입이 실제로 외로움을 줄였기 때문입니다. 즉 우정은 타고나는 성향이 아니라 학습과 지원으로 강화될 수 있는 관계입니다.

모델 답변 07

교수님이 가족과 친구를 비교하라고 하면

30초 모델 답변

가족은 의무와 규범의 힘이 더 크고, 친구는 선택성과 동질성이 더 큰 관계라고 말하면 됩니다. 그래서 친구는 행복감과 자기표현에서 특별한 의미를 가질 수 있습니다.

모델 답변 08

이 글을 한 문장으로 다시 말하면

30초 모델 답변

노년기의 우정은 행복과 건강을 지키는 선택된 지지관계라고 요약할 수 있습니다. 감정적 위로, 실질적 도움, 외로움 완화, 개입 가능성까지 모두 포함한 관계입니다.
