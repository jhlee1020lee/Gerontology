모델 답변 01

이 논문의 핵심 주장을 한 문장으로 말해보라면

30초 모델 답변

부모 돌봄이 형제 긴장을 높이는 이유는 역할 부담만이 아니라 편애 인식이 함께 작동하기 때문입니다. 돌봄을 맡은 자녀도, 누가 선호된다고 느끼는 자녀도 형제관계에서 더 큰 긴장을 경험했습니다.

모델 답변 02

왜 편애 인식이 그렇게 중요하다고 보나

30초 모델 답변

형제는 실제 자원 분배만이 아니라 공정하게 대우받는지에 매우 민감하기 때문입니다. 누가 더 선호된다고 느끼는 순간 돌봄 결정 자체가 불공평하게 읽힙니다.

모델 답변 03

within-family differences 관점이 왜 필요한가

30초 모델 답변

같은 가족 안에서도 자녀별 경험이 다르기 때문에 가족 전체 평균으로는 갈등을 설명할 수 없기 때문입니다. 누군가는 돌봄을 하고, 누군가는 안 하고, 누군가는 선호받는다고 느끼고, 누군가는 배제감을 느낍니다.

모델 답변 04

논문이 말하는 상호작용 효과를 쉽게 설명해보라면

30초 모델 답변

돌봄만 있을 때보다 돌봄과 편애 인식이 겹칠 때 형제 긴장이 더 크게 올라간다는 뜻입니다. 즉 부담과 서운함이 따로가 아니라 서로 증폭된다는 이야기입니다.

모델 답변 05

이 연구가 돌봄 지원정책이나 실천에 주는 함의는

30초 모델 답변

돌봄 조정은 노동 분배만이 아니라 형제 간 감정과 공정성 인식을 함께 다뤄야 합니다. 누가 무엇을 하느냐뿐 아니라 왜 그렇게 결정되었는지 설명하고 협의하는 과정이 중요합니다.

모델 답변 06

어머니 중심 분석이라는 점을 어떻게 해석해야 하나

30초 모델 답변

편애 인식과 돌봄 기대가 어머니 기준으로 측정되었기 때문에 부부 부모 모두를 대표한다고 볼 수는 없습니다. 하지만 later-life family에서 어머니가 관계 조정의 중심이 되는 경우가 많아 의미 있는 출발점이 됩니다.

모델 답변 07

한국 맥락으로 연결하면 어떤 질문이 가능할까

30초 모델 답변

부모 돌봄을 둘러싼 형제 갈등이 실제 노동량뿐 아니라 인정, 차별, 장남·장녀 기대와 어떻게 얽히는지를 물을 수 있습니다. 특히 누가 가까이 살고 누가 경제력을 갖고 있는지가 편애 인식과 결합할 수 있습니다.

모델 답변 08

교수님이 '다시 말해봐' 하면 어떻게 다시 정리할까

30초 모델 답변

부모 돌봄 갈등은 일의 양만이 아니라 누가 더 사랑받고 인정받는다고 느끼는지의 문제라는 뜻입니다. 같은 간병 상황도 편애 인식이 끼어들면 형제관계가 훨씬 더 날카로워집니다.
