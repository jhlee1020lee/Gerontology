이 글을 어떻게 읽었는지

15개 모델 답변

각 답변은 먼저 이 글을 어떻게 읽었는지, 무엇에 초점을 맞췄는지, 어떤 기대가 바뀌었는지를 말하고, 바로 구체적인 읽기 근거를 붙이는 20~40초 구술 연습 답변입니다.

모델 답변 01

age와 time to death를 구분하는 글로 읽었다

30초 모델 답변

저는 이 논문을 초고령기 성격연구라기보다, age와 time to death를 갈라서 읽었습니다. 처음에는 둘이 비슷한 시간 변수처럼 보였는데, 읽고 나니 같은 85세라도 죽음까지 남은 시간은 다를 수 있어서 이 구분이 핵심이었습니다. 그래서 저는 이 글이 나이 효과만 보는 게 아니라 삶의 말기라는 시간을 따로 잡아 보려는 연구라고 이해했습니다.

모델 답변 02

전반적 쇠퇴보다 성격 특성별 차이가 더 중요했다

30초 모델 답변

처음에는 말기 변화니까 성격이 전반적으로 다 약해지는 쪽을 먼저 떠올렸습니다. 그런데 읽고 나서는 성격 특성마다 방향이 다르다는 점이 더 중요했습니다. 신경증은 마지막 10년 동안 평균적으로 올라가고, 외향성과 개방성은 내려가니까, 이 논문은 한 방향 쇠퇴보다 어떤 성격 특성이 어떻게 다르게 움직이는지를 보여주는 글로 읽었습니다.

모델 답변 03

모두가 똑같이 변한다기보다 평균수준 궤적을 보는 글로 읽었다

30초 모델 답변

처음에는 이런 연구를 보면 노년기에는 다 비슷하게 변하겠다고 생각하기 쉽습니다. 그런데 읽고 나서는 이 논문이 각 개인이 똑같이 변한다고 말하는 게 아니라, 집단의 평균수준 궤적을 보는 연구라는 점이 더 중요하다고 봤습니다. 그래서 저는 결과를 읽을 때도 노년기에 다 이렇다고 받기보다, 평균적 흐름과 개인차를 구분해서 읽으려고 했습니다.

모델 답변 04

건강 하나보다 자원마다 붙는 성격 특성이 다르다고 봤다

30초 모델 답변

처음에는 말기 성격변화면 건강 상태가 거의 다 설명할 거라고 생각했습니다. 그런데 읽고 나서는 건강 하나로 묶으면 안 되고, 자원마다 붙는 성격 특성이 다르다고 봤습니다. 예를 들면 외로움은 신경증 쪽에 더 가깝고, 사회활동은 외향성과 개방성 쪽에 더 관련됩니다. 그래서 이 논문은 자원 전체를 한 덩어리로 보기보다, 어떤 자원이 어떤 변화와 연결되는지를 구분해서 읽게 했습니다.

모델 답변 05

종단연구의 강점과 표본 한계를 같이 봤다

30초 모델 답변

처음에는 종단연구니까 말기 성격변화에 대해 꽤 강하게 말할 수 있겠다고 생각했습니다. 그런데 읽고 나서는 BASE의 매우 고령 사망자 표본이라는 점과 외향성, 개방성 쪽의 선택효과 가능성을 같이 봐야 한다고 느꼈습니다. 그래서 저는 이 논문을 좋은 종단 증거로는 읽되, 여기서 바로 강한 인과 주장까지 가는 글로는 읽지 않았습니다.

모델 답변 06

죽음이 가까워질수록 모든 성격이 다 같이 가팔라진다고 읽지 않았다

30초 모델 답변

처음에는 삶의 말기면 세 특성 모두 임종에 가까울수록 더 급하게 변할 거라고 생각했습니다. 그런데 읽고 나서는 time to death가 비교적 분명하게 붙는 건 신경증 기울기라는 점이 더 중요했습니다. 외향성과 개방성은 줄어들긴 하지만 같은 방식으로 다 가팔라진다고 보긴 어려워서, 저는 이 논문을 말기 효과를 한꺼번에 일반화하지 말라고 하는 글로 읽었습니다.

모델 답변 07

병 개수보다 실제 기능 제한이 더 중요하다고 읽었다

30초 모델 답변

처음에는 질환을 많이 가진 사람이 성격변화도 더 클 거라고 생각했습니다. 그런데 읽고 나서는 의사 진단 동반질환 개수보다 실제 장애나 기능 제한이 더 직접적인 위험요인처럼 보였습니다. 그래서 저는 건강을 읽을 때도 병명 목록보다 지금 실제로 얼마나 수행이 제한되는지가 외향성과 개방성 변화에 더 중요하다고 봤습니다.

모델 답변 08

개인적 통제감과 타인 통제감을 같은 통제감으로 읽지 않았다

30초 모델 답변

처음에는 통제감이면 높을수록 다 좋은 변수라고 생각했습니다. 그런데 읽고 나서는 personal control과 other-directed control을 갈라서 봐야 한다고 느꼈습니다. 개인적 통제감은 외향성과 개방성의 높은 수준 쪽에 가깝고, 타인 통제감은 신경증과 연결되지만 말기에는 일부 개방성과도 같이 읽힙니다. 그래서 저는 이 변수를 단순히 높고 낮음이 아니라 통제의 방향 차이로 읽었습니다.

모델 답변 09

사회활동과 외로움을 같은 사회관계 변수로 보지 않았다

30초 모델 답변

처음에는 사회관계 변수면 다 비슷하게 작동할 거라고 생각했습니다. 그런데 읽고 나서는 사회활동과 외로움이 같은 사회적 포괄 안에 있어도 성격과 연결되는 방향이 다르다고 봤습니다. 외로움은 신경증에 더 가깝고, 사회활동은 외향성과 개방성 쪽에 더 관련되기 때문입니다. 그래서 저는 사회관계를 양이 많고 적음의 문제보다 어떤 경험으로 측정했는지를 구분해서 읽었습니다.

모델 답변 10

처음에는 죽음이 다 설명할 줄 알았지만 읽고 나서는 자원 가용성이 더 중요했다

30초 모델 답변

처음에는 이 논문이 결국 죽음이 가까워질수록 성격이 어떻게 달라지는지를 보여주는 글이라고 생각했습니다. 그런데 완전 조건모형까지 읽고 나서는 age나 time to death 자체보다 건강, 통제감, 사회적 포괄 같은 자원 가용성이 최종 해석의 중심이라고 봤습니다. 그래서 저는 이 글을 죽음 하나가 다 설명하는 논문이 아니라, 말기 변화가 자원과 적응 맥락 속에서 달라지는 글로 읽었습니다.

모델 답변 11

Big Five 전체를 다 본 논문으로 읽지 않았다

30초 모델 답변

처음에는 성격 논문이니까 Big Five 전체를 다 본 연구라고 생각했습니다. 그런데 읽고 나서는 이 논문이 신경증, 외향성, 개방성 세 특성만 측정한 연구라는 점을 먼저 붙여야 한다고 봤습니다. 그래서 저는 이 결과를 성격 전체의 결론처럼 넓게 말하기보다, 세 특성에서 확인된 말기 궤적이라고 한정해서 읽었습니다.

모델 답변 12

인지수행을 단순 보호요인 하나로 읽지 않았다

30초 모델 답변

처음에는 인지수행이 높으면 성격변화도 전반적으로 더 안정적일 거라고 생각했습니다. 그런데 읽고 나서는 그렇게 단순하지 않다고 봤습니다. 인지수행이 높을수록 개방성 수준은 더 높지만, 예상과 달리 평균 이상 인지수행 집단에서는 외향성 감소가 더 가팔랐기 때문입니다. 그래서 저는 인지수행을 무조건 보호요인이라기보다 trait별로 다르게 읽어야 하는 변수라고 봤습니다.

모델 답변 13

타인 통제감을 무조건 부정적으로 읽지 않았다

30초 모델 답변

처음에는 타인에게 통제된다고 느끼는 건 거의 다 부정적인 신호라고 생각했습니다. 그런데 읽고 나서는 말기에는 그 변수도 조금 다르게 봐야 한다고 느꼈습니다. 타인 통제감은 신경증과 연결되지만, 죽음 약 7년 전부터는 더 높은 개방성과도 같이 읽히기 때문입니다. 그래서 저는 이 논문이 말기의 통제감을 단순 상실이 아니라 도움과 의존의 맥락까지 같이 보게 만든다고 읽었습니다.

모델 답변 14

선택효과를 단순 탈락 문제로만 읽지 않았다

30초 모델 답변

처음에는 선택효과라고 하면 그냥 연구 중간에 사람이 빠지는 정도로만 생각했습니다. 그런데 읽고 나서는 누가 끝까지 남아 있느냐가 결과 방향 자체를 덜 부정적으로 보이게 만들 수 있다는 점이 더 중요하다고 봤습니다. 특히 외향성과 개방성에서는 긍정적 선택효과 가능성이 있어서, 저는 보이는 감소폭을 그대로 전체 말기 노년기로 일반화하지 않으려고 했습니다.

모델 답변 15

실천적 함의를 성격 교정보다 취약한 자원 맥락을 보는 쪽으로 읽었다

30초 모델 답변

처음에는 이런 논문이면 결국 어떤 성격이 더 나쁘고 좋은지를 말하는 쪽으로 읽기 쉬웠습니다. 그런데 읽고 나서는 성격 자체를 교정하자는 메시지보다, 기능 제한이 많고 통제감이 낮고 사회적으로 덜 포괄된 사람이 더 취약한 궤적을 보인다는 점이 더 중요하다고 봤습니다. 그래서 저는 이 논문의 함의를 성격 낙인보다 취약한 자원 맥락을 더 빨리 알아보는 데 있다고 읽었습니다.
