  3. 기능적 신경영상은 노년기 인지 차이가 사실상 없다는 점을 보여 주었다.
  4. 기능적 신경영상은 고전 이론을 모두 잘못된 것으로 만들었다.

  4. 복측 시각피질이 더 선명하게 분화된다.

  4. 구조적 뇌영상은 언제나 잘못된 결과를 주기 때문이다.

14. 저자들이 인지 훈련 연구를 다시 중요하게 보게 된 이유로 가장 알맞은 것은 무엇인가?

  2. 뇌가 재조직화와 가소성을 보인다면 개입 가능성도 원리상 열려 있기 때문이다.
  3. 기능적 신경영상이 더 이상 필요 없기 때문이다.
