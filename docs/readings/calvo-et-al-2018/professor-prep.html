모델 답변 01

이 논문의 핵심 주장을 한 문장으로 말해보라면

30초 모델 답변

은퇴는 완전히 탈표준화된 것이 아니라 여전히 규범성과 비가역성이 남아 있으면서 집단별로 강하게 층화되어 있다고 말할 수 있습니다. 비전형 경로는 늘었지만 누구나 똑같이 자유로운 것은 아니었습니다.

모델 답변 02

왜 sequence approach가 필요한가

30초 모델 답변

은퇴는 한 시점 사건이 아니라 상태와 전환의 배열이기 때문입니다. 풀타임, 파트타임, 실업, 완전은퇴, 재취업이 어떤 순서로 이어지는지 봐야 경로가 보입니다.

모델 답변 03

moderately destandardized라는 표현을 어떻게 설명할까

30초 모델 답변

비전형 경로가 늘었지만 전통적 질서와 연령 규범이 완전히 사라지지 않았다는 뜻입니다. 즉 다양성은 커졌지만 아무 경로나 똑같이 흔한 것은 아닙니다.

모델 답변 04

stratification을 왜 같이 봐야 하나

30초 모델 답변

경로 다양성이 누구에게나 같은 방식으로 주어지지 않기 때문입니다. 여성, 저학력층, 흑인 집단은 더 불안정하고 덜 규범적인 경로를 더 자주 경험했습니다.

모델 답변 05

unretirement가 왜 중요한가

30초 모델 답변

은퇴가 비가역적인 종결만은 아니라는 점을 보여 주기 때문입니다. 다시 일로 복귀하는 경로가 존재하면 전통적 은퇴서사를 수정해야 합니다.

모델 답변 06

연구방법을 짧게 설명해보라면

30초 모델 답변

HRS 종단자료 7,881명을 60-61세부터 70-71세까지 여섯 차례 추적해 sequence analysis를 했다고 설명하면 됩니다. 즉 단면이 아니라 시간 흐름 속 경로를 본 연구입니다.

모델 답변 07

한국 맥락으로 연결하면 어떤 질문이 나올까

30초 모델 답변

한국의 은퇴 다양성도 계층과 성별에 따라 불평등하게 분배되는지 묻는 질문으로 연결할 수 있습니다. 정년퇴직, 재취업, 자영업, 비정규노동 경로가 누구에게 집중되는지를 봐야 합니다.

모델 답변 08

이 논문을 다시 한 문장으로 요약하면

30초 모델 답변

은퇴의 다양성은 사실이지만 그 다양성은 여전히 규범과 불평등의 틀 안에서 분배된다고 요약하면 됩니다. 즉 자유로운 선택의 시대라는 말만으로는 부족합니다.
