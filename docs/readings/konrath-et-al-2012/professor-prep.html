모델 답변 01

이 논문의 핵심은 무엇인가

30초 모델 답변

봉사행동 자체보다 왜 봉사하는지가 사망위험과 더 밀접하게 연결된다는 점입니다. 타인지향적 동기는 낮은 사망위험과 연결됐지만 자기지향적 동기는 그렇지 않았습니다.

모델 답변 02

왜 동기가 중요하다고 보나

30초 모델 답변

같은 봉사라도 동기가 다르면 활동이 주는 의미와 스트레스 조절 방식이 달라질 수 있기 때문입니다. 타인지향 동기는 더 깊은 의미감과 관계지향성을 만들 수 있습니다.

모델 답변 03

self-oriented motive 결과를 어떻게 말해야 정확할까

30초 모델 답변

자기지향 동기는 비자원봉사자와 비슷한 사망위험을 보였다고 말하는 것이 정확합니다. 즉 자기지향 동기가 반드시 더 해롭다고 단정한 것은 아닙니다.

모델 답변 04

연구방법을 짧게 설명하면

30초 모델 답변

WLS 고령자 자료를 사용해 4년 후 사망위험을 logistic regression으로 분석했다고 답하면 됩니다. 건강, 성격, 사회지지, 실제 봉사행동도 함께 통제했습니다.

모델 답변 05

eudaimonic well-being을 왜 연결하나

30초 모델 답변

타인을 위한 봉사가 더 깊은 의미와 목적감을 줄 수 있어 건강효과가 다를 수 있기 때문입니다. 즉 단순히 사람을 만나는 사회활동보다 더 깊은 안녕을 만들 수 있다는 설명입니다.

모델 답변 06

봉사와 건강을 사회적 자원으로 해석한다는 건 무슨 뜻인가

30초 모델 답변

봉사가 사람을 더 연결하고 지지망을 만들며, 그 관계가 건강에 영향을 줄 수 있다는 뜻입니다. 하지만 논문은 단순 사회적 접촉보다 동기 차이가 더 중요할 수 있다고 봅니다.

모델 답변 07

한국 맥락으로 연결하면 어떤 질문이 가능할까

30초 모델 답변

노년기 자원봉사가 사회공헌인지, 자기관리인지, 경력관리인지에 따라 경험과 효과가 달라지는지 물을 수 있습니다. 즉 참여의 양뿐 아니라 의미 구조를 묻는 연구가 필요합니다.

모델 답변 08

이 논문을 한 문장으로 다시 정리하면

30초 모델 답변

자원봉사의 건강효과는 얼마나 하느냐보다 왜 하느냐에 달릴 수 있다고 요약할 수 있습니다. 타인지향 동기가 있을 때만 사망위험 감소가 뚜렷했습니다.
