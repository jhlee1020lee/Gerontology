핵심 개념 / 용어

1. 환경노년학

노화과정을 물리적·공간적 환경과의 관계 속에서 연구하는 분야다.

  • 왜 중요한가: 장의 이론적 출발점이다.
  • 연결 지점: 환경노년학

2. 장이론

인간의 행동을 개인과 환경의 함수로 보는 Lewin의 관점이다.

  • 왜 중요한가: 환경의 중요성을 설명하는 기본 틀이다.
  • 연결 지점: 장이론

3. 환경압박-역량 모델

환경이 요구하는 압박과 개인의 적응 역량 간 관계를 설명하는 모델이다.

  • 왜 중요한가: 노인과 환경 상호작용을 구체적으로 읽게 한다.
  • 연결 지점: 환경압박이론

4. 지역사회 환경

물리적, 사회적, 심리적 특성을 함께 포함하는 생활환경을 뜻한다.

  • 왜 중요한가: 장 전체에서 다루는 핵심 대상이다.
  • 연결 지점: 지역사회 환경

5. 장소애착

자신이 사는 장소에 대해 느끼는 정서적 유대와 의미를 뜻한다.

  • 왜 중요한가: 왜 익숙한 지역에 계속 살고 싶어 하는지 설명한다.
  • 연결 지점: 지역사회 환경

6. 물리적 환경

주거, 거리, 교통, 보행환경 같은 공간적 조건을 뜻한다.

  • 왜 중요한가: 건강과 이동 가능성을 직접 좌우한다.
  • 연결 지점: 지역사회 환경

7. 사회적 환경

이웃관계, 지역 유대, 상호작용 기회 같은 사회적 조건을 뜻한다.

  • 왜 중요한가: 고립과 참여, 안전감에 영향을 준다.
  • 연결 지점: 지역사회 환경

8. aging in place

나이 들어도 익숙한 집과 지역사회에서 계속 살아가는 것을 뜻한다.

  • 왜 중요한가: 정책과 실천에서 가장 중요한 목표 개념 중 하나다.
  • 연결 지점: Aging in Place
