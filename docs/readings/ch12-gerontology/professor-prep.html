이 글을 어떻게 읽었는지

15개 모델 답변

각 답변은 먼저 이 글을 어떻게 읽었는지, 무엇에 초점을 맞췄는지, 어떤 기대가 바뀌었는지를 말하고, 바로 구체적인 읽기 근거를 붙이는 20~40초 구술 연습 답변입니다.

모델 답변 01

건강을 병 없음으로 끝내지 않은 이유

30초 모델 답변

저는 이 장을 건강의 정의부터 넓히는 장으로 읽었습니다. WHO는 건강을 단순히 질병이나 장애가 없는 상태가 아니라 신체적, 정신적, 사회적으로 안녕한 상태로 봅니다. 그래서 노년기 건강을 말할 때 진단명만이 아니라 기능, 마음 상태, 사회적 삶과 돌봄 부담까지 같이 봐야 합니다.

모델 답변 02

노년기 건강을 사회문제로 읽은 이유

30초 모델 답변

저는 "노년기 건강을 사회문제로 읽은 이유"를 단순 배경 설명이 아니라 글의 해석 방향을 바꾸는 초점으로 읽었습니다. 노년기 건강은 개인의 통증이나 병원 방문만의 문제가 아니라고 읽었습니다. 교재는 65세 이상 고령자가 인구의 약 14%였지만 전체 의료비의 39%를 사용했다고 제시합니다. 건강 악화는 가족 돌봄 시간, 의료재정, 장기요양 부담으로 이어지기 때문에 건강은 개인관리이면서 동시에 사회정책 문제입니다.

모델 답변 03

활동제한을 핵심 지표로 잡은 이유

30초 모델 답변

저는 "활동제한을 핵심 지표로 잡은 이유"를 단순 배경 설명이 아니라 글의 해석 방향을 바꾸는 초점으로 읽었습니다. 노인 건강을 볼 때 병명이 있는지보다 실제 일상생활을 해낼 수 있는지가 더 직접적일 때가 많다고 읽었습니다. 활동제한은 ADL, IADL, 와병일수, 활동제한율처럼 생활 수행능력을 묻는 지표입니다. 그래서 같은 만성질환을 가진 노인이라도 혼자 씻고 이동하고 외출할 수 있는지에 따라 돌봄 필요가 달라집니다.

모델 답변 04

ADL과 IADL을 나누어 말해야 하는 이유

30초 모델 답변

저는 "ADL과 IADL을 나누어 말해야 하는 이유"를 단순 배경 설명이 아니라 글의 해석 방향을 바꾸는 초점으로 읽었습니다. ADL과 IADL은 둘 다 일상생활능력이지만 수준이 다릅니다. ADL은 옷 입기, 씻기, 식사 같은 기본 자기유지이고, IADL은 돈 관리, 약 챙기기, 교통수단 이용 같은 독립생활 능력입니다. 2017년 노인실태조사에서 65세 이상 ADL 독립은 91.3%, IADL 독립은 75.4%라서 IADL이 더 먼저 취약해질 수 있습니다.

모델 답변 05

85세 이상 수치를 붙여야 하는 이유

30초 모델 답변

저는 연령이 올라갈수록 도구적 생활능력의 취약성이 커진다는 점을 수치로 기억해야 한다고 봤습니다. 교재는 85세 이상에서 ADL 완전자립이 68.1%, IADL 완전자립이 32.7%에 불과하다고 제시합니다. 그래서 초고령층 건강은 병원 진단보다 독립생활 유지와 돌봄 설계를 중심으로 봐야 합니다.

모델 답변 06

질병지표와 기능지표를 섞지 않은 이유

30초 모델 답변

저는 "질병지표와 기능지표를 섞지 않은 이유"를 단순 배경 설명이 아니라 글의 해석 방향을 바꾸는 초점으로 읽었습니다. 질병지표는 유병률, 사망원인, 만성질환 개수처럼 병적 상태를 보는 방식이고, 기능지표는 실제 수행능력을 보는 방식입니다. 교재는 65세 이상 노인의 89.5%가 3개월 이상 앓는 만성질환이 있고 51%는 3가지 이상 만성질환을 가진다고 제시합니다. 하지만 병이 많다는 사실이 곧 기능상실 정도를 자동으로 말해 주지는 않습니다.

모델 답변 07

주관적 건강평가를 가볍게 보지 않은 이유

30초 모델 답변

저는 "주관적 건강평가를 가볍게 보지 않은 이유"를 단순 배경 설명이 아니라 글의 해석 방향을 바꾸는 초점으로 읽었습니다. 주관적 건강평가는 객관적 질병지표와 항상 일치하지 않지만 노년기 삶을 이해하는 데 중요하다고 읽었습니다. 자신의 건강을 나쁘게 평가한 노인은 더 우울하고 삶에 더 불만족할 수 있으며, 향후 건강결과와도 관련됩니다. 그래서 노인 건강 답변에서는 진단, 기능, 본인이 느끼는 건강을 분리해서 말하는 것이 좋습니다.

모델 답변 08

정신건강을 정상노화로 넘기지 않은 이유

30초 모델 답변

저는 "정신건강을 정상노화로 넘기지 않은 이유"를 단순 배경 설명이 아니라 글의 해석 방향을 바꾸는 초점으로 읽었습니다. 이 장은 나이가 들면 정신건강문제가 필연적으로 늘어난다고 단순화하지 않습니다. Zarit의 지적처럼 젊은층보다 노인이 모든 정신건강문제를 더 많이 겪는다고 말하기는 어렵습니다. 치매를 제외한 많은 정신건강문제는 노화 자체보다 경제적 어려움, 사별, 건강 악화, 사회적 고립 같은 생활조건과 더 밀접하게 연결됩니다.

모델 답변 09

우울을 한 가지 진단명으로만 보지 않은 이유

30초 모델 답변

치매 유형과 가역성을 같이 말한 이유
