질문에 먼저 직답한 뒤, 10초·30초·60초 답변과 꼬리질문 대응을 비교하세요. 추상적인 감상보다 개념, 근거, 한계, 한국 맥락을 붙이는 연습에 맞춰져 있습니다.

모델 답변 01

이 장에서 친구와 이웃을 따로 다루는 이유는

30초 모델 답변

가족 밖 관계가 노년기 삶의 질을 지지하는 중요한 자원이기 때문입니다. 친구는 자발성과 친밀성, 이웃은 근접성과 일상 접촉이라는 다른 강점을 가집니다.

모델 답변 02

친구관계의 핵심 특성을 한 문장으로 말하면

30초 모델 답변

친구관계는 선택과 자발성, 그리고 동질성에 기반한 관계라고 정리할 수 있습니다. 가족처럼 주어진 관계가 아니라 서로 선택하고 유지한다는 점이 핵심입니다.

모델 답변 03

이웃관계는 왜 여전히 중요하다고 보나

30초 모델 답변

가까이 산다는 사실 자체가 일상 도움과 위기 대응의 자원이 되기 때문입니다. 친구보다 덜 친밀해도 근접성 덕분에 즉각적인 지원이 가능할 수 있습니다.

모델 답변 04

사회 관계망을 구조와 기능으로 나누는 이유는

30초 모델 답변

관계가 몇 개 있는지와 그 관계가 실제로 무엇을 해 주는지는 다른 문제이기 때문입니다. 규모가 작아도 강한 지지가 있을 수 있고, 규모가 커도 실질적 도움은 약할 수 있습니다.

모델 답변 05

사회적 관계와 건강을 연결할 때 핵심은

30초 모델 답변

사회적 관계는 정서적 안정, 정보, 실질 도움을 통해 건강과 복지를 지지한다는 점입니다. 반대로 갈등적 관계는 스트레스를 높이고 건강을 해칠 수도 있습니다.

모델 답변 06

관계망이 줄어드는 것이 항상 나쁜가

30초 모델 답변

항상 그렇지는 않습니다. 나이 들수록 덜 중요한 관계를 줄이고 의미 있는 관계에 집중할 수 있기 때문입니다. 따라서 관계 수 감소 자체보다 어떤 관계가 남는지가 더 중요합니다.

모델 답변 07

교수님이 친구와 가족 차이를 다시 말해보라면

30초 모델 답변

가족은 주어진 관계이고 친구는 선택한 관계라는 점이 가장 큰 차이입니다. 그래서 친구는 자발성과 동질성이 크고, 가족은 책임과 규범의 힘이 더 강합니다.

모델 답변 08

이 장을 한 문장으로 요약하면

30초 모델 답변

노년기 삶의 질은 가족만이 아니라 친구, 이웃, 관계망 전체가 어떻게 기능하는지에 달려 있다고 요약할 수 있습니다. 중요한 것은 관계 수보다 질, 구조보다 기능, 지원과 갈등의 양면성입니다.
