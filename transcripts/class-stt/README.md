- 이 폴더는 `수업 녹음 STT`만 보관한다.
- `content/readings/*/raw.txt`는 읽기 자료 원문 추출본이므로 여기와 성격이 다르다.
- 파일명 형식은 `YYYY-MM-DD-<reading-slug>-class-stt.txt`로 통일한다.
